Notes

Moderator partial (~) — Moderators can access the admin panel read-only. They cannot change roles, ban users, or delete accounts.

All restrictions are enforced server-side via Supabase Row Level Security policies and SECURITY DEFINER functions. Client-side checks are UI-only and cannot be bypassed to gain elevated access.

First account = auto admin — The handle_new_user trigger promotes the very first registered account to admin automatically.
